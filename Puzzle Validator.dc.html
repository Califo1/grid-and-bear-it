What each type is checked against
Sudoku, KenKen, Kakuro, Nonogram
Solved from the printed clues alone. Exactly one answer, and it must equal the printed solution.
Crossword
Every entry matches the grid, crosses another entry, and carries a real clue — a generated stand-in counts as a failure.
Fill-in
The bank matches the grid's slots, and the bank can be placed exactly one way.
Word search
Every listed word is actually in the grid; duplicates and unplaced words are reported.
Cryptogram
The cipher is a true one-to-one substitution, no letter stands for itself, and it decodes to the stated answer.
Ladder, anagram, scramble, math, maze, trivia
Each step, pairing, sum and path is recomputed and compared with what the page prints.

Generation runs in a worker with a per-puzzle time limit, so a generator that never returns is reported as a timeout instead of freezing this page. Serve the folder over http — a worker cannot import scripts from a file:// path.
